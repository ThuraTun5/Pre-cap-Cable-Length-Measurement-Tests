Breadboard basics for this project

Rails

The thick bars in the drawings are the long rails of the breadboard. Mark them with tape: 3V3 (yellow) and GND (black). From T7 on, motor power never goes on these rails.

Chip orientation

The 74LVC245 sits across the centre gap of the breadboard. The notch marks the top. Pin 1 is top-left; pins count down the left side (1–10), then up the right side (11–20).

Many GND pins = one ground

The ESP32 has 7 GND pins and four 3.3 V pins, all joined inside the board. In T7 and T8 several wires use different GND / 3.3 V pins so that no wires cross. They're all the same ground or the same 3.3 V.

Power order (motor tests)

On: ESP32 USB first, then the motor supply. Off: motor supply first. Never plug or unplug a motor while the supply is on.
