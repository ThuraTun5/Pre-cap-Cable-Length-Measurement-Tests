How to read the drawings: a name tag such as GND or 3V3 means "connect to that rail". All tags with the same name are connected together, normally through a breadboard rail. A dot = wires joined. A small hop (arc) = wires cross but are not connected. A red × = pin left unconnected.

Breadboard basics for this project

Two rails = two tags

Use one long rail as 3V3 (fed from the ESP32 3V3 pin) and the other as GND. Mark them with tape. From T7 on, the motor supply VM gets its own separate rail. Never put VM on the 3V3 or 5V rail.

Chip orientation

The 74LVC245 straddles the centre gap of the breadboard. The notch (or dot) marks the top: pin 1 is top-left, and pins count down the left side (1–10), then up the right side (11–20).

Jumper wires slip

Push every jumper fully in, and tape the encoder cable down so it can't pull out. A loose encoder wire shows up as jumping or missing counts in T4.

Power order (motor tests)

On: ESP32 USB first, then the motor supply. Off: motor supply first. Never plug or unplug a motor while the supply is on.
