Two motors in sync

After this page you can explain how two drivers share one UART wire, why the motors stay in sync, and why motor 2 is mirrored.

Very short page. It builds on T07.

Section 1Two drivers on one UART wire: addresses

Both drivers hear every message on the shared PDN wire. Each message starts with an address, and only the driver with that address answers. The address comes from the MS1 and MS2 pins at power-up:

DriverMS1MS2Address
1GND (0)GND (0)0
23.3 V (1)GND (0)1

If driver 2's MS1 is also on GND, both have address 0, they answer at the same time, and the replies are garbage. That's why the program checks both drivers separately with i.

In one sentence: same wire, different addresses; MS1 = 3.3 V makes driver 2 address 1.

Section 2 · the hard ideaWhy the motors stay in sync

The cable is clamped at both ends. If one end turns more than the other, the cable twists. So both motors must make exactly the same number of steps.

The program gives both motors identical speed and acceleration and starts them one right after the other (a few microseconds apart). Each motor gets its own hardware step generator (RMT channel 0 and 1), so the pulses don't depend on what the CPU is doing. When they stop, both have made the same number of steps, and the "difference" shown is 0.

Steppers don't measure their position; they just follow the pulses. If a motor is blocked or overloaded, it can skip steps without anyone noticing. Our motors turn a light cable slowly at 700 mA, so this shouldn't happen. A real check would need a sensor on each clamp head (an idea for later).

In one sentence: same pulses for both, made in hardware, so the step difference stays 0.

Section 3Why motor 2 is mirrored

The motors face each other. Imagine both turning "clockwise", each seen from its own shaft. Seen from one side of the jig, they would then turn against each other and twist the cable. So motor 2 must turn the opposite way to motor 1.

The program does this by inverting motor 2's DIR pin (setDirectionPin(PIN_DIR2, false)). Both step counts still go up together, so the difference stays 0. Swapping the two wires of one coil would also reverse a motor. Mirroring in software is easier to change and to check, so the m command flips it and saves the choice.

In one sentence: facing motors must turn opposite ways, and the software mirrors motor 2.
